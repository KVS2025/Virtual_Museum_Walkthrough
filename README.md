# 🎨 Museum Walkthrough (S4DS Task 2)

A responsive **virtual museum walkthrough** built using **React + Vite + TailwindCSS**.  
The app displays famous museums, their images, interesting historical facts, and country details with flags.  

---

## 🚀 Features
- 📸 High-quality museum images  
- 🏛️ Historical facts on click  
- 🌍 Country name with flag and gradient style  
- 📱 Fully responsive layout with TailwindCSS  

---

## 🛠️ Tech Stack
- [React](https://react.dev/)  
- [Vite](https://vitejs.dev/)  
- [TailwindCSS](https://tailwindcss.com/)
